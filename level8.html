Level 8

Files: saving and reading simple data

open · write · append · read · close

Main ladder prep: Save, View and Search Scores

What you are learning

  1. A file lets data stay after the program ends.
  2. Append mode "a" adds to the end of a file.
  3. A newline character moves the next score onto a new line.
  4. Using with open(...) automatically closes the file afterwards.

Why this matters

File handling feels harder because the program is working with something outside the screen. Start with one simple save before moving to reading and searching.

Worked example

Read the code first. Then predict the output before you run it.

name = input("Name: ")
score = input("Score: ")

with open("scores.txt", "a") as file:
    file.write(name + "," + score + "\n")

print("Score saved")

Line-by-line explanation

Part of the codeWhy it is there
open("scores.txt", "a")Opens the file in append mode.
as fileGives the open file a temporary name.
"\n"Starts a new line so the next score is not stuck on the same line.

Drag-and-drop practice

Put the save-score program in the best order.

name = input("Name: ")
score = input("Score: ")
with open("scores.txt", "a") as file:
file.write(name + "," + score + "\n")
print("Score saved")

Your tiny build

  1. Ask for a name and a score.
  2. Append the data to scores.txt.
  3. Run it twice and check the file has two lines.
