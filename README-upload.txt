Python Builder Ladder - Multi-page version

Upload instructions for GitHub Pages:
1. Create a new repository, for example: python-builder-ladder
2. Upload the CONTENTS of this folder, not the folder itself.
3. Make sure index.html is in the root of the repository.
4. Go to Settings > Pages.
5. Set Source to main branch and /root.
6. Save and open the published link when GitHub Pages finishes deploying.

Files included:
- index.html: small homepage with level links
- learning-map.html: links builder levels to the main ladder
- teacher-notes.html: guidance for using the scaffold
- level0.html to level9.html: separate learning/task pages
- css/style.css: shared colour scheme and layout
- js/app.js: drag-and-drop, gap checking and copy-code buttons
- assets/python-logo.svg: local Python-style logo asset
