Teacher notes

This builder ladder is best used with students who benefit from a more guided route before moving into the full independence of the main Python Coding Ladder.

First steps route

Model the worked example live. Students then complete the interactive task with you before typing the tiny build. Their success criterion is accuracy, not speed.

Builder route

Students read the explanation, complete the interactive practice, and then build the tiny program without copying the whole worked example.

Challenge route

Students use the matching builder level as a five-minute warm-up, then move straight to the matching level on the main ladder.

Important teaching point

Do not let students stay on drag-and-drop only. The interactive tasks are a bridge. Every level should end with students typing, running and testing code in IDLE.
