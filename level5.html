Level 5

Strings: using part of a word

indexing · concatenation · lower case

Main ladder prep: Username Generator

What you are learning

  1. A string is a piece of text.
  2. Indexing gets one character from a string.
  3. Python starts counting positions at 0.
  4. lower() changes text to lowercase.

Why this matters

Username generators often build a new string from parts of existing strings. This feels strange at first because Python counts the first character as position 0.

Worked example

Read the code first. Then predict the output before you run it.

first_name = input("First name: ")
surname = input("Surname: ")
username = first_name[0] + surname
username = username.lower()
print(username)

Line-by-line explanation

Part of the codeWhy it is there
first_name[0]Gets the first character from first_name.
+ surnameJoins the first initial to the surname.
username.lower()Makes the username lowercase so it looks consistent.
