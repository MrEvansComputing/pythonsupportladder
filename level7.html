Level 7

Loops: stop repeating yourself

for loops · lists · iteration

Main ladder prep: Improved Quiz with Repetition

What you are learning

  1. A loop repeats code.
  2. A list stores several values together.
  3. A for loop goes through each item in the list one at a time.

Why this matters

Loops reduce repeated code. Instead of writing three separate print lines, one loop can process every item in a list.

Worked example

Read the code first. Then predict the output before you run it.

subjects = ["IT", "Maths", "Science"]

for subject in subjects:
    print("I study", subject)

Line-by-line explanation

Part of the codeWhy it is there
subjects = [...]Creates a list with three values.
for subject in subjects:Takes one item from the list each time the loop repeats.
indented print lineThis line repeats once for each item.
