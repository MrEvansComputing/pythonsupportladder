Level 0

Code has an order

Sequencing · reading programs before writing them

Bridge skill: step-by-step coding practice

What you are learning

  1. A Python program runs from the top line to the bottom line.
  2. If the order is wrong, the program can still run but the result may not make sense.
  3. Before writing code, good programmers read the code and predict what will happen.

Why this matters

Students often try to guess the answer by typing random lines. This level slows them down and builds the habit of reading code in order before they build anything themselves.

Worked example

Read the code first. Then predict the output before you run it.

print("Welcome to Python")
print("This program has three lines")
print("Each line runs in order")

Line-by-line explanation

Part of the codeWhy it is there
print("Welcome to Python")The first message appears first because it is the first line.
print("This program has three lines")The computer moves down to the next instruction.
print("Each line runs in order")The final line appears last.

Drag-and-drop practice

Put these code lines into the best order so the user is greeted first, told the topic second, and encouraged last.

print("Hello coder!")
print("Today we are learning sequencing.")
print("Now try running the code.")

Your tiny build

  1. Type the three lines into IDLE.
  2. Run the program.
  3. Change one message so it sounds more like you.
