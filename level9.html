Mini app: one menu, two choices

menu · while loop · selection · combined skills

Main ladder prep: Full Student Helper App

What you are learning

  1. A menu gives the user choices.
  2. A while loop keeps the menu running until the user chooses to stop.
  3. Selection decides what happens for each menu option.
  4. A bigger program is just smaller skills combined carefully.

Why this matters

The final main ladder task can feel huge. A menu app becomes manageable when learners see it as input, selection, loops and print statements working together.

Worked example

Read the code first. Then predict the output before you run it.

choice = ""

while choice != "3":
    print("1. Say hello")
    print("2. Show help")
    print("3. Exit")
    choice = input("Choose: ")

    if choice == "1":
        print("Hello")
    elif choice == "2":
        print("Ask for help if you are stuck")

print("Goodbye")

Line-by-line explanation

Part of the codeWhy it is there
choice = ""Creates the variable before the loop starts.
while choice != "3":Keeps repeating until the user chooses option 3.
if / elifChecks which menu option the user typed.
