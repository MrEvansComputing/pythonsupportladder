Level 2

Input and variables: storing answers

input · variables · output using stored data

Main ladder prep: Name Badge Generator

What you are learning

  1. input() asks the user a question.
  2. A variable stores the answer so the program can use it later.
  3. A good variable name explains what is being stored.

Why this matters

We use variables because the program cannot know the user’s answer in advance. The input is stored so the program can reuse it in later lines.

Worked example

Read the code first. Then predict the output before you run it.

name = input("What is your name? ")
subject = input("What is your favourite subject? ")
print("Hello " + name)
print("You like " + subject)

Line-by-line explanation

Part of the codeWhy it is there
name =Creates a variable called name.
input("What is your name? ")Shows a question and waits for the user to type.
+ nameJoins the fixed message to the answer stored in name.

Drag-and-drop practice

Put the badge generator lines in the correct order.

name = input("What is your name? ")
subject = input("Favourite subject? ")
print("Hello " + name)
print("You like " + subject)
