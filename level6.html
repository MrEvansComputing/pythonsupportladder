Level 6

Score counters: changing a variable

selection · score variable · updating values

Main ladder prep: Mini Quiz Game

What you are learning

  1. A score starts at 0.
  2. When an answer is correct, the score can increase.
  3. score = score + 1 means take the old score and add one.

Why this matters

Many students think score = score + 1 looks mathematically wrong. In programming, the right side is calculated first, then the answer is stored back into the variable.

Worked example

Read the code first. Then predict the output before you run it.

score = 0
answer = input("What language are we learning? ")

if answer.lower() == "python":
    score = score + 1
    print("Correct")
else:
    print("Try again")

print("Score:", score)

Line-by-line explanation

Part of the codeWhy it is there
score = 0Creates the score variable at the start.
answer.lower() == "python"Checks the answer while ignoring capital letters.
score = score + 1Updates the score by adding one.

Drag-and-drop practice

Put the one-question quiz in the correct order.

score = 0

if answer.lower() == "python":
score = score + 1
print("Score:", score)

Your tiny build

  1. Create a score variable.
  2. Ask one quiz question.
  3. If the answer is correct, add 1 to the score.
  4. Print the final score.
