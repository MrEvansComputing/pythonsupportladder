Output: making the computer speak

print statements · text output · clear layout

Main ladder prep: Name Badge Generator

What you are learning

  1. print() is used to output information on the screen.
  2. Text must go inside speech marks.
  3. Brackets tell Python what information print() should display.

Why this matters

This is the safest first coding skill because students can see an immediate result. It also introduces accurate syntax without needing variables yet.

Worked example

Read the code first. Then predict the output before you run it.

print("Student Badge")
print("Name: Alex")
print("Subject: Computer Science")

Line-by-line explanation

Part of the codeWhy it is there
printThe command that tells Python to display something.
("Student Badge")The brackets contain the thing we want to display.
speech marksPython needs speech marks because this is text, not a variable name.
