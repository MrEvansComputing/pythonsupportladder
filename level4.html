Level 4

Selection: making a decision

if · else · comparison · indentation · len

Main ladder prep: Password Strength Checker

What you are learning

  1. Selection lets the program choose between two paths.
  2. if checks whether a condition is True.
  3. else runs when the condition is False.
  4. Indented lines belong inside the if or else block.

Why this matters

A password checker needs a decision. The program must choose whether the password is long enough or too short.

Worked example

Read the code first. Then predict the output before you run it.

password = input("Enter a password: ")

if len(password) >= 8:
    print("Strong enough")
else:
    print("Too short")

Line-by-line explanation

Part of the codeWhy it is there
len(password)Counts how many characters are in the password.
>= 8Checks whether the length is 8 or more.
indented print linesThese lines only run inside the matching branch.

Drag-and-drop practice

Put the password checker in the best order.

password = input("Enter a password: ")
if len(password) >= 8:
print("Strong enough")
else:
print("Too short")

Your tiny build

  1. Ask the user to enter a password.
  2. Use len() to check if it has at least 8 characters.
  3. Print one message for strong enough and one message for too short.
