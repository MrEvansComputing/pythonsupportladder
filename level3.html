Level 3

Numbers: input is text until we convert it

int · casting · arithmetic · calculator programs

Main ladder prep: Revision Time Calculator

What you are learning

  1. input() gives Python text, even when the user types a number.
  2. int() converts a whole number from text into an integer.
  3. After conversion, Python can do arithmetic with the value.

Why this matters

Without int(), Python may treat the user’s answer like text. That is why calculations often crash or join values together instead of adding them.

Worked example

Read the code first. Then predict the output before you run it.

lessons = int(input("How many lessons? "))
minutes = lessons * 60
print("That is", minutes, "minutes")

Line-by-line explanation

Part of the codeWhy it is there
int(input(...))Asks the question, then converts the answer into a whole number.
lessons * 60Multiplies the number of lessons by 60.
print(..., minutes, ...)Commas allow Python to print text and numbers together more easily.
